# Payment_Acceptance_In_Telegram_Bot

# 🤖 Telegram Bot для продажи доступа в закрытый канал

Бот для автоматической продажи доступа в закрытый Telegram канал через платежную систему PayMaster (ЮKassa). После успешной оплаты пользователь получает одноразовую инвайт-ссылку.

## 🚀 Возможности

- ✅ Регистрация пользователей в базе данных
- 💳 Прием платежей через PayMaster (тестовый режим)
- 🔒 Защита от повторной обработки одного платежа
- 📝 Сохранение истории всех транзакций
- 🔗 Автоматическая генерация одноразовых инвайт-ссылок
- ⚠️ Обработка ошибок и логирование
- 🗄️ Хранение данных в SQLite

## 🛠 Технологии

- Python 3.9+
- aiogram 3.x
- aiosqlite
- PayMaster API / ЮKassa

## ⚙️ Настройка

### 1. Получение токенов

**Токен бота:**
- Напиши [@BotFather](https://t.me/BotFather)
- Создай нового бота командой `/newbot`
- Получи токен вида `1234567890:AAF...`

**Токен провайдера (PayMaster):**
- В диалоге с [@BotFather](https://t.me/BotFather) выбери своего бота
- Выбери `Payments` → `Connect PayMaster: test`
- Получи токен вида `1744374395:TEST:...`

### 2. Настройка канала

1. Создай закрытый Telegram канал
2. Добавь бота в канал как **администратора**
3. Выдай боту право **приглашать пользователей** (`invite_users`)
4. Получи ID канала:
   - Перешли любое сообщение из канала в [@userinfobot](https://t.me/userinfobot)
   - Или используй Telegram Desktop (Настройки → Продвинутые → Show Peer IDs)

### 3. Подготовка кода

Замени значения в коде:
```python
TOKEN = 'твой_токен_бота'
provider_token = 'твой_токен_провайдера'
chat_id = ID_твоего_канала  # например -1001234567890
```

## 🎮 Использование

### Команды бота

- `/start` - Начало работы, регистрация пользователя
- Кнопка **Оплатить** - Получение счета на 100₽
- Кнопка **Помощь** - Информация о боте

### Процесс покупки

1. Пользователь нажимает **Оплатить**
2. Бот отправляет счет через Telegram Payments
3. Пользователь вводит данные карты (тестовые: `1111 1111 1111 1111`)
4. После успешной оплаты бот:
   - Проверяет уникальность платежа
   - Создает одноразовую инвайт-ссылку
   - Отправляет ссылку пользователю
   - Сохраняет информацию о платеже в БД

### Тестовые карты PayMaster

| Номер карты | Срок | CVV | Назначение |
|------------|------|-----|------------|
| 1111 1111 1111 1111 | любой | любой | Успешная оплата |
| 2222 2222 2222 2222 | любой | любой | Ошибка оплаты |

## 📊 Структура базы данных

### Таблица `users`
Хранит информацию о зарегистрированных пользователях:

| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Первичный ключ |
| telegram_id | INTEGER | ID пользователя в Telegram |
| username | TEXT | Имя пользователя (может быть NULL) |

### Таблица `payments`
Хранит историю всех платежей:

| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Первичный ключ |
| telegram_id | INTEGER | ID пользователя (внешний ключ) |
| charge_id | TEXT | Уникальный ID платежа от провайдера |
| amount | INTEGER | Сумма платежа (в копейках) |
| payment_date | TIMESTAMP | Дата и время платежа |

## 🔒 Безопасность

- ✅ `charge_id` имеет ограничение `UNIQUE` в БД для защиты от дублей
- ✅ Проверка существования платежа перед выдачей товара
- ✅ Обработка ошибок при создании инвайт-ссылок
- ✅ Защита от повторной отправки одного чека
- ✅ Логирование ошибок для отладки
